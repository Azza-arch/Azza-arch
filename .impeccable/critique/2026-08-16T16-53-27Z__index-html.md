## Priority Issues
[P0] No visible email address anywhere on the page — blocks conversion goal for visitors without a configured mail client. Fix: render address as visible text/link fallback near the form.
[P0] Hero has no personal cutout photo — core "personal/technical/credible" brand requirement unimplemented. Fix: source photo, place with scoped restrained parallax.
[P1] Mobile nav (.nav-links) disappears below 720px with no replacement — majority-mobile SME audience loses in-page navigation. Fix: add mobile menu affordance.
[P1] Glow blobs (hero x2, contact x1) + .glass panels (x2) directly contradict explicit "avoid glassmorphism/glow" brief. Fix: replace with flat/bordered treatment already used elsewhere.
[P1] Structural sameness: identical eyebrow+headline formula repeated across all 7 sections (detector: 9 kicker hits). Fix: vary section composition/rhythm.
[P2] Palette drift: undeclared indigo-700 accent, inconsistent eyebrow color logic by section background. Fix: standardize to stated navy/blue/lime/purple system.
[P2] Project cards are gradient-tile placeholders (ai-color-palette x2), no real screenshots; Unity-games block (5 cards, one at 430px min-height) outweighs actual web/product work (4 cards) in visual size. Fix: use real screenshots, rebalance size toward freelance-relevant work.
