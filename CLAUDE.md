# HaziqBuilds project rules

Read [README.md](README.md) for the site architecture and [PRODUCT.md](PRODUCT.md) for its positioning, pricing, ownership, credits, and approved claims before changing public pages. These files are the sources of truth for those subjects.

## Preserve

- Keep the site as static HTML, CSS, and JavaScript with no build step or framework unless approved.
- Keep the `haziqbuilds` wordmark, navy and white surfaces, and official lime accent `#c7ff41`.
- Keep Space Grotesk for headings and Plus Jakarta Sans for body copy.
- Preserve working navigation, enquiry behavior, responsive layouts, and accurate project credits.

## Content

- Lead with shipped work and explain Haziq's role accurately.
- Never invent results, user counts, testimonials, client relationships, or project ownership.
- Label fictional concepts and employer work clearly.
- Use `PRODUCT.md` for package pricing and business terms; keep public copy in English, direct, and practical.

## Implementation

- Follow existing page patterns and shared behavior in `assets/app.js`.
- Keep keyboard access, visible focus, reduced-motion support, labeled controls, and useful behavior when optional scripts fail.
- Keep responsive navigation breakpoints and JavaScript state behavior aligned across Home, Work, and About.
- Update page metadata and sitemap entries when public routes or content change.
- Make the smallest scoped change; do not rewrite unrelated pages or projects.
- Do not install dependencies, add tests, or run expensive checks unless asked.

## Approval required

Ask before changing pricing, business terms, brand identity, project credits or claims, public contact paths, security or deployment configuration, or site architecture.
