## DENAI — permainan pengembaraan Matematik Tambahan dalam pelayar

**Apa:** Permainan platform 2D percuma di mana pelajar menggunakan fungsi untuk menggerakkan
mesin, membina jambatan dan membuka gerbang. Dalam Bahasa Melayu, dimainkan di telefon atau
komputer tanpa muat turun atau akaun.

**Topik semasa:** Fungsi — KSSM Matematik Tambahan Tingkatan 4, Bab 1 (input/output, gubahan,
songsang).

**Khalayak sasaran:** Pelajar Tingkatan 4–5 di Malaysia; guru dan pusat tuisyen Matematik
Tambahan; ibu bapa.

**Ciri sedia ada:** 3 level (Dunia 1), Peta Dunia, simpanan automatik, kemenangan automatik,
papan pendahulu nama samaran (pilihan, persetujuan jelas), kad keputusan boleh dikongsi,
sokongan telefon & papan kekunci, menghormati tetapan "kurang gerakan" peranti.

**Kedudukan pendidikan:** Latihan konsep melalui eksperimen — jawapan salah boleh dicuba
semula tanpa hukuman. Tiada dakwaan peningkatan markah (belum ada kajian).

## Rangka kerja prospek penaja (dalaman)

**Langkah:** senarai → kelayakan → keutamaan → draf mesej → **kelulusan pemilik** → hubungi →
rekod respons.

| Kriteria kelayakan | Soalan |
|---|---|
| Kesesuaian khalayak | Adakah mereka sudah melayan pelajar/guru sekolah menengah di Malaysia? |
| Keselamatan untuk kanak-kanak | Adakah produk sesuai dipaparkan kepada bawah 18 tahun? (Tolak: perjudian, minuman manis bertenaga, pinjaman, dll.) |
| Nilai pendidikan | Adakah kerjasama menambah nilai, bukan sekadar logo? |
| Saiz minta | Adakah jumlah yang diminta sepadan dengan deliverable sebenar? |
| Risiko reputasi | Adakah mereka pernah dikaitkan dengan isu privasi kanak-kanak? |

Jenis prospek dipisahkan dalam jejak (spreadsheet): **Penaja komersial** · **Pelanggan pilot** ·
**Geran** · **Rakan komuniti** — setiap satu ada mesej, deliverable dan metrik berbeza.

Templat mesej pertama (draf, jangan hantar tanpa kelulusan):
> Salam [nama]. Saya membangunkan DENAI, permainan pelayar percuma untuk topik Fungsi Matematik
> Tambahan Tingkatan 4. [Satu metrik sebenar jika ada.] Saya sedang mencari [jenis kerjasama]
> untuk [deliverable spesifik]. Boleh saya kongsi demo 60 saat? Tiada data pelajar dikongsi
> dalam sebarang kerjasama.
