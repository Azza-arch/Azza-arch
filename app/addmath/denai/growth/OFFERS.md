**[Pembangunan akan datang]**. Harga ialah hipotesis untuk diuji, bukan keputusan.

## 1. Akses permainan percuma
| | |
|---|---|

## 2. Sumbangan penyokong / produk penyokong
| | |
|---|---|
| Deliverable semasa | **Tiada lagi.** Pilihan: (a) sumbangan sukarela tanpa ganjaran dalam permainan; (b) **[Pembangunan akan datang]** PDF "Buku Kerja Fungsi DENAI" (latihan bercetak berpandukan Level 1-1–1-3). |
| Pelanggan sasaran | Dewasa: ibu bapa, alumni, pemain dewasa, komuniti pendidik. **Bukan** pelajar bawah umur. |
| Hipotesis harga | Sumbangan RM5 / RM12 / RM25 (pilihan); buku kerja RM9–RM15. |
| Usaha penghantaran | (a) rendah: halaman penyedia sumbangan; (b) sederhana: 10–20 jam menulis & menyusun PDF. |
| Obligasi sokongan | Resit automatik penyedia; pertanyaan muat turun dijawab dalam 3 hari bekerja. |
| Bayaran & pemulangan | Halaman checkout dihoskan penyedia (pautan keluar — tiada data kad di DENAI). Sumbangan: tiada pemulangan kecuali tersalah caj. PDF: pemulangan penuh dalam 7 hari jika fail rosak/tidak boleh dimuat turun. Semak keperluan pendaftaran perniagaan/cukai pemilik. |
| Syarat sebelum lancar | Kelulusan pemilik; terma & notis privasi penyedia disemak; produk siap sepenuhnya sebelum dijual; tiada kelebihan permainan (tiada pay-to-win, tiada level dikunci); label jelas "sumbangan, bukan pembelian ciri". |
| Ujian minat tanpa bayaran | Butang "Saya mahu menyokong" di landing yang menghitung klik (atau tinjauan 1 soalan) **sebelum** checkout wujud. |

## 3. Pilot guru / pusat tuisyen (kecil)
| | |
|---|---|
| Deliverable semasa | Permainan percuma (1-1–1-3) + sesi onboarding dalam talian 30 minit oleh pemilik. **[Pembangunan akan datang]**: rancangan pengajaran 2 × 40 minit, lembaran kerja bercetak, panduan guru. **Tiada** papan pemuka kelas atau akaun pelajar. |
| Pelanggan sasaran | Pusat tuisyen swasta dan guru Matematik Tambahan (penggunaan peribadi di kelas). Sekolah kerajaan memerlukan kebenaran pentadbiran — bukan sasaran awal. |
| Hipotesis harga | 3 pilot pertama **percuma** sebagai rakan reka bentuk (pertukaran: maklum balas berstruktur). Selepas itu RM150–RM300 setiap pusat bagi satu penggal (≈4 minggu). |
| Usaha penghantaran | Bahan pertama: ~15–25 jam; setiap pilot: ~3–4 jam (onboarding, satu semakan pertengahan, satu sesi maklum balas). |
| Obligasi sokongan | Respons dalam 2 hari bekerja semasa pilot; pembetulan pepijat kritikal sebelum sesi kelas seterusnya. |
| Bayaran & pemulangan | Invois + pindahan bank/DuitNow selepas perjanjian ringkas ditandatangani. Pemulangan penuh jika dibatalkan sebelum sesi pertama; pro-rata selepas itu. |
| Privasi | Tiada data pelajar dikumpul oleh DENAI dalam pilot. Pelajar main tanpa daftar; leaderboard kekal pilihan dan boleh diabaikan. Maklum balas guru tanpa nama pelajar. |
| Syarat sebelum lancar | Bahan pengajaran siap; perjanjian pilot satu muka surat; kelulusan pemilik; sesi demo diuji pada peranti kelas (telefon pelajar / makmal). |
| Ukuran kejayaan | % pilot yang mahu sambung berbayar; maklum balas guru tentang kefahaman konsep (pemerhatian, bukan dakwaan hasil pembelajaran). |

## Apa yang TIDAK dijual
Dunia 2, akaun awan, papan pemuka guru, laporan prestasi pelajar, sijil — semua belum dibina.
Boleh disebut hanya sebagai **[Pembangunan akan datang]** tanpa tarikh dijanjikan.
