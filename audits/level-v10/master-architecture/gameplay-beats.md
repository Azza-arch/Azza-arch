## Four-step development and pacing

| Mechanic family | Introduction | Development | Twist | Resolution |
|---|---|---|---|---|
| Function mapping |04 safe probe |05 output controls mill |08 given output, choose input |16 original final missing-input question |
| Sequential functions |10 safe animated example |11 reach the actual waterworks using established movement |12 switch order and compare intermediate/final values |17 repeat correct order in bridge synthesis |
| Exploration |02 visible optional reward |06 two ladder returns |09 upper ledge and14 downward archive |18 earned secrets remain optional |

Intensity alternates: movement warm-up → low-risk optional crate → gap → probe → gear → café rest → workshop → demonstration → roof movement → pipe reasoning → overlook → optional cave → easy descent → final synthesis → arrival. Do not add enemies or time pressure to the mathematics. Composition is the one substantial main-path curriculum expansion; inverse remains optional.

There are no intentionally empty running stretches longer than roughly one camera reveal: landmarks, low steps, ladders, checkpoints or local feedback interrupt travel. Measure this in implementation; if novices spend more than90 seconds stalled at a required puzzle, reveal one worked intermediate step rather than shortening the whole level.
