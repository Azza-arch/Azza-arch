# Science Quest — gaps requiring custom artwork or UI composition

The pack is a general-purpose control kit. It supplies buttons, basic controls, arrows, stars, and common status symbols, but no Science Quest-specific world art. “Custom required” below means no matching asset was found in this audited archive; it does not prescribe how the future project must obtain it.

## Priority gaps

| Need | Why Science Quest needs it | Finding |
| --- | --- | --- |
| Magnet & Force artwork | Topic identity, visual explanations, interactable objects | No magnet, poles, field lines, force arrows/diagrams, or science illustrations. |
| Topic illustrations | Future Space, Human Body, Plants, Animals, Electricity modules | No topic-specific icons, characters, or objects. |
| Characters/mascot | Friendly guidance and learner feedback | No characters or mascot art. Do not infer a mascot from UI icons. |
| Landscape backgrounds | Main menu, topic scenes, mission/gameplay screens | No usable backgrounds or environments; preview images are generic UI demonstrations. |
| Panels and dialog frames | Instructions, questions, results, pause/settings, feedback | No dedicated panels/windows. Button rectangles are not a complete dialog system. |
| Progress and reward system | Lesson progress, level completion, achievements | Stars exist, but no trophy, coin, badge set, hearts/lives, or complete progress bar. |
| Settings and topic symbols | Navigation and settings discovery | No gear/settings, sound/music, home, magnet, or science-topic symbol family. |
| Rich menu tabs | Topic and section navigation | No explicit tab component; would need a composed control treatment. |

## Available generic building blocks

Blue/Green/Yellow button treatments, check/radio-like controls, sliders, simple arrows, stars, play/repeat symbols, input frames, and two display fonts can support a first design-system composition. They do not replace science illustrations or accessible UI behavior.
